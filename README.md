# CodeAlpha_HangmanGame1



## 📌 About

This is a simple text-based Hangman Game developed using Python.

The player has to guess a hidden word one letter at a time. The player can make a maximum of 6 incorrect guesses.

## ✨ Features

* Randomly selects a word from a predefined list
* Allows the player to guess one letter at a time
* Shows correctly guessed letters
* Allows a maximum of 6 wrong guesses
* Displays Win and Game Over messages
* Simple console-based interface

## 🛠️ Technologies Used

* Python
* Random Module
* While Loop
* If-Else Statements
* Strings
* Lists

## ▶️ How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python hangman.py
```

## 🎯 Game Rules

* Guess one letter at a time.
* A correct letter is revealed.
* An incorrect letter increases the wrong-guess count.
* The player has a maximum of 6 incorrect guesses.
* Guess the complete word before reaching 6 wrong guesses to win.
